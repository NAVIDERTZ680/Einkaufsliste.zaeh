# Navin Einkaufsliste

Öffentliche Bedienoberfläche für die vom Eigentümer gewünschte Veröffentlichung auf GitHub Pages. Enthält ausschliesslich die fertigen Webseiten-Dateien in `docs/`. Keine Serverquellen, Datenbankinhalte, persönlichen Zugangscodes oder Kontoschlüssel.

Aktivierung: Settings → Pages → Deploy from a branch → main → /docs → Save.

Zum Benutzen «Liste verbinden» wählen, im privaten Verbindungstab anmelden, zur GitHub-Seite zurückkehren und den persönlichen Code eingeben. Den Verbindungstab offenlassen. Am iPhone Safari mit normalen Tabs verwenden; mobile Hintergrundtabs können pausiert werden und müssen dann kurz geöffnet werden.

Artikel lassen sich hinzufügen, scannen, bearbeiten und abhaken. Erledigte Artikel erscheinen nach Datum sortiert unter «Abgehackt». Die Daten werden in der bisherigen privaten Speicherung gehalten; Internet erforderlich.
